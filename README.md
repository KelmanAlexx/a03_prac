МАГАЗИН ЭЛЕКТРОНИКИ — WPF

Технологии:
- WPF / C#
- .NET Framework 4.8
- C# 7.3
- PostgreSQL
- ADO.NET / Npgsql 4.1.13

ПОДГОТОВКА БАЗЫ
1. Создайте базу storesыs (если она ещё не создана).
2. Импортируйте предоставленный chudos.sql.
3. Если у PostgreSQL другие параметры, откройте App.config и измените строку подключения.

ПОДГОТОВКА ПРОЕКТА
1. Откройте ShoeStore.csproj в Visual Studio 2022 и выше на Windows.
2. Дождитесь восстановления NuGet-пакетов.
3. Проверьте параметры подключения в App.config.
4. Запустите проект клавишей F5.

УЧЁТНЫЕ ЗАПИСИ
Учётные записи берутся из таблиц users и roles. Для просмотра:
SELECT u.login, u.password, r.name, u.full_name
FROM users u
JOIN roles r ON r.id = u.role_id
ORDER BY r.id, u.id;

СТРУКТУРА
Models — модели данных и сессия.
Data — подключение к БД и SQL-запросы.
Helpers — загрузка и сохранение изображений.
Окна — авторизация, список товаров, редактирование товаров и заказы.

ВАЖНЫЕ ОСОБЕННОСТИ
- Цена products.price имеет тип integer, поэтому форма принимает целые рубли.
- Изображения хранятся в папке Images рядом с exe.
- При оформлении заказа остатки уменьшаются в одной транзакции с созданием заказа.
- При удалении заказа остатки не возвращаются на склад.
- Сумма заказа вычисляется по текущей цене товара с учётом скидки.
- Для WPF необходима Windows-среда.
